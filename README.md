# Telegram-чат на GREEN-API

Веб-интерфейс для отправки и получения сообщений в Telegram через [GREEN-API](https://green-api.com).

Стек: React, TypeScript, Vite.

```bash
npm install
npm run dev
```

## Использование

1. Введите `apiUrl`, `idInstance`, `apiTokenInstance` из личного кабинета GREEN-API.
2. Нажмите ✎ и введите номер телефона получателя.
3. Напишите сообщение и нажмите Enter.
